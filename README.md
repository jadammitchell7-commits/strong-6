# Strong 12

A 12-week, 3-day-a-week strength tracker. Open the page, pick the week and day, log weight and reps, tick sets off. Export everything to CSV for a spreadsheet.

- Works on phones (add to home screen) and computers
- No accounts, no servers: the log is saved in the browser on the device
- Download a backup from the **Export** tab to move devices

## Publish with GitHub Pages
1. Create a repo (e.g. `strong-12`) and push these files to `main`.
2. Repo **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`.
3. After a minute the site is live at `https://<username>.github.io/strong-12/`.

## Program
Day 1 legs + push, Day 2 hinge + pull, Day 3 full body. Weeks 1–4 Foundation, 5–8 Build, 9–12 Strength. Weeks 4, 8 and 12 are easy weeks. Edit the `DAYS` list at the top of the script in `index.html` to change exercises.
